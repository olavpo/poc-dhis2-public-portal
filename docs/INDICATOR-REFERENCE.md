# Indicator Reference — what each portal variable is built from

This document maps **every variable shown in the DNEMIS Education Statistics portal** to the
exact DHIS2 `dx` (indicator or data-element) UID(s) behind it, and the formula where a value
is computed rather than read directly.

It is generated by hand from the single source of truth, the page template
**`scripts/asc-pages/template.mjs`**, plus the extractor config
**`scripts/dhis2-extract/config/asc.yaml`**. If those change, update this file. Names are from
the extracted `evidence/sources/census/dx.csv`.

## Conventions used throughout

- **Period / level.** Every query filters `periodType = 'YEARLY'` and `pe = '2024'` (the ASC
  reference year) and scopes to one org unit (Federal, a State, or an LGA).
- **Direct vs. computed.**
  - *Direct* — the value is read straight from DHIS2 with `max(... value)` (one cell per
    `ou`/`pe`). Used for **indicators** (rates/ratios/%) — DHIS2 has already aggregated them
    correctly, and rates must never be summed/averaged.
  - *Computed* — built in SQL as `factor × Σnumerator ÷ denominator`, only ever from
    **data elements** (counts), which *are* additive.
  - *Summed* — `sum(... value)` across rows; only for **counts** (enrolment, schools, etc.).
- **The Total / Public / Private toggle.** A store (`components/ownership.js`) selects which of
  three baked query results a component shows. The three come from different fact tables:
  - **Total** → `census.fact`
  - **Public** → `census.fact_ownership` where `category_name like 'Public%'`
  - **Private** → `census.fact_ownership` where `category_name like 'Private%'`
  (`census.fact_ownership` is the Ownership org-unit-group-set cut, group set `gAmNV64G0pZ`.)
- **`dx` type matters.** Counts (enrolment, teachers, classrooms, labs, schools, report
  counts, female/total teachers) are summed; ratios/percentages are read directly. See the
  "Let DHIS2 aggregate indicators" rule in `AGENTS.md`.

## 2. Reporting & completeness (`ReportStats`)

Three numbers — **Submitted**, **Expected**, **Completeness %** — over the six ASC census
forms. All read from `census.fact` (split by *form*, not by the ownership group set).

```
Submitted    = Σ (actual-report dx)
Expected     = Σ (expected-report dx)
Completeness = round(100 × Submitted ÷ Expected, 1)
```
